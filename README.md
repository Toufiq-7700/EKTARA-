# 🌳 Recursive Garden

> Four recursive algorithms become a relaxing audiovisual experience.

A tree grows on screen, and the tree **is** the melody. The Nørgård infinity series generates pitch, Tower of Hanoi drives the bass, Euclidean rhythm (Bjorklund) creates percussion, and an L-system draws the growing tree — all from one seed.

**🚧 Under construction — see prompt-log/ for the full build history.**

## Quick Start

```bash
npm install
npm run dev
```

## Stack

- Vite + vanilla JavaScript
- Tone.js (audio synthesis)
- Canvas 2D (visuals)
- Vitest (testing)
